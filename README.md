# RubriksSolver
Learning and helping to solve a Rubiks Cube

# Goals
- Research/ find existing recipies for solving 2x2 and 3x3 cubes- 
- Website, can use external libraries like threejs
- Vue.js
- Visual 3d representation of 2x2 or 3x3 cube that can be rotated with mouse movements
- Reset to starting position
- manually assign tiles for a scrambled position
- Animated step by step to show solution
- Learning/teaching/testing mode: The app should teach the user solving concepts
- gemini API model or/and local gemma model can be attached for natural expression
- Starting position should be able to be assigned from two pictures if taken if cube is facing corner and then opposite corner
- Site will run statically deployed in a existing jboss deploy folder
